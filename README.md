# 🌐 Gunal Basskaran — Personal Portfolio Website

A modern, responsive, and minimal **one-page personal portfolio website** showcasing my skills, projects, and contact information.  
Built using pure **HTML, CSS, and JavaScript** with a focus on clean UI, performance, and accessibility.

---

## 🚀 Live Demo

👉 https://gunalbasskaran.github.io/Portfolio/

---

## 📌 Features

- One-page scrolling layout  
- Clean & modern UI (White / Black / Orange theme)  
- Fully responsive for all devices  
- Smooth scrolling & animations  
- Mobile-friendly navigation menu  
- Project showcase with live demo links  
- Contact form with validation  
- Custom favicon & loading screen  

---

## 🛠 Tech Stack

- HTML5  
- CSS3 (Flexbox, Grid, Custom Properties)  
- JavaScript (ES6+)  
---

## 📸 Projects Featured

1. Escape_Run – Browser-based game  
2. Novapay – Payment website UI  
3. Resilinet – Weather alert website  
4. SharePlate – Food sharing concept website  
5. TerraSheild – Climate awareness website  

Each project includes:
- Description  
- Tech stack  
- GitHub link  
- Live demo

## ⚙️ How to Use Locally

1. Clone the repository  
git clone https://github.com/gunalbasskaran/Portfolio.git


2. Open folder  
cd Portfolio


3. Open `index.html` in your browser
